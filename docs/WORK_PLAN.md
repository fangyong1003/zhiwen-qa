# 知问开发与验收计划

更新日期：2026-09-10。

## 目标与范围

先交付一个可重复启动、核心问答流程可验证的内部试用版本。第一版沿用 React / Vite、Express 和 MySQL，知识库暂按全员共享管理；部门或文档级授权在独立里程碑实施。真实模型质量、成本和性能必须通过实际数据验收，不以模拟响应代替。

## 里程碑

| 顺序 | 工作 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| M1 | 修复启动、切片、JSON 读取、账号权限和上传失败处理；补配置模板 | 原有故障有回归用例；停用/降权下一次请求生效；索引失败可重试 | 已完成，本地验收通过 |
| M2 | 核心链路自动化回归和 CI | 独立 MySQL 下通过初始化、登录、上传、索引、问答、历史、引用下载、反馈、审计；模拟模型仅用于验证协议与持久化 | 本地通过；CI 已配置，远端运行待确认 |
| M3 | 资料访问边界与员工/管理员体验 | 文档授权规则落实到检索与下载；上传进度、请求失败与会话切换行为可验收 | 待开始 |
| M4 | 真实模型效果与部署验收 | 使用真实资料与密钥评估答案、引用、延迟与成本；完成备份恢复、部署和运行监控 | 待开始 |
